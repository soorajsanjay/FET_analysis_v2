How to use the dashboard

  1. Choose the folder containing measurement files. Enable subfolders only when the batch is nested.
  2. Optionally create or select a configuration, then review geometry, polarity, oxide, extraction, and quality settings.
  3. Run analysis and watch progress. The pipeline creates one input-named Excel workbook and one standalone HTML report per file, plus batch and TLM workbooks.
  4. Start in Sample overview: select a KPI, inspect individual device points and mean with 95% confidence interval, then click a row or point to open its detailed HTML or Excel evidence.
  5. Use TLM explorer for fit-level RcW/resistivity, fit residuals, device metrics versus channel length, and fit parameters versus bias. RcW and resistivity are fit-level quantities, not per-length measurements.
  6. Use the local interactive chart controls to pan, box-zoom, select, autoscale, reset axes, inspect hover details, filter legends, and export PNGs. A requested log axis falls back to linear if non-positive data are present.
  7. Enable retained PNGs only when separate image files are required; HTML reports already embed their figures.

Statistics: the dashboard shows the arithmetic mean and a 95% confidence interval calculated as 1.96 × sample SD / √N. With N=1 the value is shown but the interval is unavailable; very small groups are labelled limited evidence. Filtered dashboard statistics are view-only and are never written back to canonical reports.

Analysis methods

Segmentation and cleaning: sweep direction and fixed-bias groups are detected from measured columns. Non-finite, compliance-limited, and configured noise-floor points are excluded from applicable fits while raw data remains available in Excel.

Transfer: threshold voltage uses the configured extraction method; transconductance is derived numerically; field-effect mobility uses gm, Cox, channel length, width, and drain bias; subthreshold swing is fit in log-current space subject to leakage and noise rules. Ion, Ioff, Ion/Ioff, hysteresis, and DIBL use the effective settings recorded in each workbook.

Output: output conductance is derived from dId/dVd. Linear-region resistance is fitted inside the configured drain-voltage window and reported with fit quality.

TLM: total resistance is compared across channel lengths using ordinary least squares with a free intercept. Contact resistance comes from the intercept and sheet resistance from the width-normalized slope. LTLM* drain sweeps are treated as ungated TLM while retaining their normal IV/output analysis; transfer-curve TLM is the gated path. R², residuals, duplicate lengths, and read conditions are retained for review.

Quality: warnings expose missing geometry, leakage, compliance, sparse windows, low R², and fallback selections. Inspect raw and processed sheets and fit evidence before publication.

Outputs, temporary files, and HTML size

Each input produces <input>.xlsx, <input>_report.html, metadata JSON, and metrics JSON in the output root. Batch summary/dashboard and TLM workbooks remain in their established locations. Embedded base64 images add about one third to the original PNG bytes, trading some file size for a portable single-file report.

While analysis is running, all transient device and TLM images are contained inside one hidden .fet_work directory in the output folder. Temporary images are deleted after embedding, and the work directory is removed when analysis completes or is stopped.
